# Musik

Lege hier deinen Song als `lamborghina.mp3` ab (MP3, M4A/AAC oder OGG – dann in
`js/game.js` bei `musicInit` den Dateinamen anpassen). Das Spiel spielt ihn beim Rennen
in Schleife.

Alternativ im Spielmenü **🎵 Musik laden** tippen: Auf dem iPhone öffnet sich die Dateien-App,
dort iCloud Drive auswählen und den Song antippen. Der Song wird im Browser gespeichert
und beim nächsten Start automatisch wieder verwendet.

Ohne Song läuft ein kleiner Chiptune-Loop.
